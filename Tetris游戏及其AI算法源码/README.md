## 🧬 核心算法详解

### 1️⃣ **遗传算法基础原理**

遗传算法模拟生物进化过程，通过"优胜劣汰"的方式不断改进AI性能。

```
初始种群(50个AI) → 游戏测试 → 评估适应度 → 选择优秀个体 → 交叉变异 → 新一代
    ↑                                                                      ↓
    ←←←←←←←←←←←←← 重复进化过程 ←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←
```

#### **核心组件解释**:

- **个体(Individual)**: 一个AI智能体，包含6个决策权重
- **种群(Population)**: 50个AI智能体的集合
- **适应度(Fitness)**: AI的游戏表现评分
- **选择(Selection)**: 保留表现最好的15个AI
- **交叉(Crossover)**: 两个优秀AI"生育"产生新AI
- **变异(Mutation)**: 随机改变权重，增加多样性

### 2️⃣ **AI决策机制**

每个AI通过**6个权重参数**评估游戏局面:

```python
决策分数 = 
    height_weight × 总高度 +           # 偏好低矮布局
    holes_weight × 空洞数量 +          # 避免制造空洞  
    bumpiness_weight × 凹凸不平度 +    # 保持表面平整
    lines_weight × 可消行数 +          # 优先消行
    max_height_weight × 最大高度 +     # 控制最高点
    wells_weight × 深井数量           # 避免深坑
```

#### **决策过程**:

1. **方块出现** → 遍历所有可能的放置位置(旋转0-3次 × 位置-3到+12)
2. **模拟放置** → 对每种可能计算最终棋盘状态
3. **评分对比** → 选择得分最高的放置方案
4. **执行动作** → 发送指令给前端执行

### 3️⃣ **训练优化策略**

#### **适应度函数设计**

针对"消行能力不足"问题，我设计了**增强适应度函数**:

```python
# 传统方式 (队友版本)
fitness = 游戏分数

# 我的改进版本
fitness = 0.3×游戏分数 + 消行奖励 + 生存奖励

# 消行奖励计算
消行奖励 = 消行数 × 10 × (1 + 消行数/1000)
if 消行数 >= 1000: 消行奖励 ×= 2  # 达标双倍奖励
```

#### **智能模型更新机制**

```python
# 只有真正进步时才更新模型
if 新一代平均消行 > 上一代平均消行:
    保存最佳模型("平均提升")
elif 新一代最高消行 > 上一代最高消行:
    保存最佳模型("突破记录")
else:
    保持当前模型("无进步")
```

## 🔧 关键技术改进

### 1️⃣ **前后端统一化**

**问题**: 训练环境与实际游戏环境不一致，导致"训练好，实战差"

**解决方案**: 创建 `game_logic.py`作为**单一可信源**(Single Source of Truth)

- ✅ 方块定义完全统一
- ✅ 旋转逻辑完全一致
- ✅ 碰撞检测完全同步
- ✅ 执行过程完全匹配

### 2️⃣ **逐步执行模拟**

**改进前**: 一次性计算最终状态

```python
# 可能不准确的简化模拟
final_state = quick_simulate(piece, rotation, x)
```

**改进后**: 严格按前端步骤模拟

```python
# 完全匹配前端的执行过程
for i in range(rotation_count):
    piece = rotate_with_wall_kicks(piece)  # 逐步旋转
piece = move_to_target_x(piece, target_x)  # 逐步移动
final_state = hard_drop(piece)             # 最终下落
```

### 3️⃣ **智能权重初始化**

```python
# 针对俄罗斯方块优化的权重范围
weights = {
    "height": (-0.8, -0.2),     # 强烈避免过高
    "lines": (0.5, 1.5),        # 强化消行奖励
    "holes": (-1.2, -0.3),      # 严格惩罚空洞
    "bumpiness": (-0.8, -0.1),  # 保持平整
    "max_height": (-1.0, -0.2), # 控制危险高度
    "wells": (-0.8, -0.1)       # 避免深井陷阱
}
```

### 4️⃣ **用户体验优化**

- **跳过登录**: 专注AI测试，提高开发效率
- **实时调试**: 详细的AI决策日志
- **便捷重启**: 一键更新训练好的模型
